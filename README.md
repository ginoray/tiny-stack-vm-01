# tiny-stack-vm

An exact interpreter for make.fun's tiny stack ISA: wrapping 32-bit arithmetic, every trap code, the step and output limits, byte-for-byte output.

`main.ts` answers a whole set in one run: each /input/<id>/program.bin on its input.bin, writing /output/<id>/stdout.bin and exit.txt.
